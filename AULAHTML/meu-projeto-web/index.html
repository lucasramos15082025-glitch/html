O que aprendi até agora:

HTML:

HTML é basicamente o esqueleto do site: você só usa umas tags tipo pra colocar texto e imagem na tela

CSS:

CSS é a parte que deixa o site bonito de verdade, mudando as cores, o estilo do texto e o visual de tudo

JAVASCRIPT:

JavaScript é o que dá vida ao site e faz as coisas realmente funcionarem quando você clica em algo

como as diciplinas se completam:

A construção de um sistema web completo exige a união integrada das disciplinas de ADS. O UX/UI Design planeja uma interface intuitiva, enquanto o HTML e o CSS dão forma e estilo à tela. A Lógica de Programação e os Algoritmos ditam o comportamento e a dinâmica das interações no Front-End e Back-End. Por fim, o Banco de Dados garante a persistência segura das informações de cada usuário. Juntas, essas matérias transformam linhas de código em uma solução funcional, organizada e escalável
